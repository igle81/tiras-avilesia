# Tiras AvilesIA

Imágenes y json de las tiras cómicas diarias de AvilesIA, hechas por Fermina.

- `hoy/`: tira de hoy.avilesia.es
- `teletexto/`: tira de Teletexto

Cada carpeta lleva `tira.json` y `AAAA-MM-DD.webp` (1024×576, menos de 200 KB). Las webs las leen por raw.githubusercontent.com con un rewrite de Vercel, así que no hace falta desplegar cada día.

Repositorio público: solo imágenes y json, sin secretos.
